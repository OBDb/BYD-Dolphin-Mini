# BYD Dolphin Mini

This repository contains signal set configurations for the BYD Dolphin Mini (also known as BYD Seagull in China, Dolphin Surf in Europe, and Atto 1 in Australia/New Zealand), organized by model year and version. The files are structured to allow for easy differentiation between model generations and other vehicle parameters, ensuring accurate signal mapping for each version of the BYD Dolphin Mini.
